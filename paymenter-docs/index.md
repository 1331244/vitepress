# 服务与政策

更新日期：2026 年 10 月 26 日

本中心适用于通过 [vmaub.com](https://vmaub.com) 购买、管理和使用的云服务。下单前，请结合产品页面、订单确认信息及以下政策，确认服务是否符合你的需求。

| --- | --- |

| [退款政策](./refund.md) | 可申请退款的情况、核算方法、申请材料和退款路径 |

| [服务终止](./termination.md) | 主动取消、到期停用、违规处置和数据清理 |

## 下单前请注意

- 核对地区、配置、带宽、流量、IP 类型、购买周期以及交付方式；NAT、共享 IP 等产品可能存在端口和连接方式限制。
- **不提供无理由退款，不因个人原因提前停用而按剩余时长退款。**重复扣款、无法按约交付及依法应退的处理方式，见[退款政策](./refund.md)。
- 服务可用性承诺、退款特别规则、续费及数据保留期限，应在产品或订单页面明确载明。没有明确提供的功能，不应视为默认包含。
- **重装系统、删除实例及终止服务可能导致数据不可恢复。请自行维护独立备份；除非订单明确包含备份服务，否则不应将平台视为数据备份。**
- 退款、隐私权利或服务异常问题，请通过[站内工单](https://vmaub.com/tickets)联系。不要在公开评论或工单正文中发送登录密码、私钥或支付验证码。

## 文档如何适用

本中心中的各项政策共同构成服务约定。产品特别约定应在购买前清楚展示；任何约定都不排除适用法律规定的消费者权益及其他不可排除的权利。

本文档介绍的是 VMAUB CLOUD 提供的服务规则。Paymenter 是网站所使用的服务管理软件，不是当然的订单交易方或退款责任方。
