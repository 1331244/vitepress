# 退款政策

更新日期：2026 年 10 月 26 日

本政策适用于通过 [vmaub.com](https://vmaub.com) 购买的 VMAUB CLOUD 服务。取消续费、删除实例与退款是不同操作；取消续费或删除实例不会自动产生退款。

## 1. 不提供无理由退款

::: important 下单前请确认
**VMAUB CLOUD 不提供无理由退款。订单付款后，不接受因个人原因取消订单、提前终止服务或按剩余服务时长折算退款。**请在付款前核对产品配置、地区、线路、IP 类型、计费周期与用途限制。
:::

通常不接受退款的个人原因包括：买错产品或周期、改变使用计划、未实际使用、提前停用、自身系统或应用配置问题，以及在服务符合购买前明确说明的情况下，个人体验或第三方平台访问结果不符合预期。本平台不设置“试用后不满意退款”或默认按天退款安排。

上述规则同样适用于付款后、按约交付前因个人原因要求撤单的情况，但不排除适用法律赋予你的撤销、解除或退款权利，也不影响我们对具体订单已经作出的有效承诺。

**重复扣款、错误扣款、无法按约交付、依法应当退款等情况，不属于以本规则拒绝处理的范围。**这些情况可通过工单核实，依具体事实、订单约定和适用法律处理。

## 2. 可以申请核实的情况

- **未能交付**：已付款，但我们无法在约定条件和期限内交付，经沟通仍不能履行。
- **重复付款或错误收费**：同一订单重复扣款，或实际扣款与已经确认的应付款不符。
- **未按约提供服务**：实际交付与明确约定存在实质差异，或因我们原因持续无法提供约定服务，应结合影响、补救情况和适用法律核算。
- **依法或依有效承诺应退**：适用法律或我们已经对具体订单作出的有效承诺要求退还相应款项。

由支付渠道、网络或信息同步延迟造成的“付款成功但账单未更新”，应先核对流水和到账状态。不要为了刷新支付状态连续重复付款。

## 3. 异常退款金额如何确定

本节仅适用于核实符合前述例外的退款，不提供一般性的按剩余期限退款权利。

退款以该订单实际支付的金额为基础，不以划线价或未支付的标价计算。优惠券、赠送额度与现金付款应区分，不能把未实际支付的优惠金额视为可退现金，也不能因使用优惠而额外追加未曾约定的费用。

重复扣款退还重复收取的部分；错误扣款更正相应差额。未能交付、未按约提供服务或依法应退的其他情况，按具体事实及应承担的责任确定金额，并向你说明核算项目和依据；不以未事先约定的更高价格倒算已使用部分。

确已发生且无法追回的域名、授权或其他第三方成本，只有在购买前已经清楚告知、与该订单直接相关且依法允许扣除时，才纳入核算；我们应说明项目及依据。不设置未事先告知的“手续费”或任意罚款。

因我们违约导致的退款，应依实际责任和适用法律确定，不适用“不提供无理由退款”规则来减轻应承担的责任。

## 4. 异常付款与例外退款的工单流程

请通过[工单](https://vmaub.com/tickets)提交：

1. 订单或账单编号。
2. 希望退款的原因，以及希望立即终止还是到期取消。
3. 支付时间、金额、渠道和可核对的交易流水；截图应遮挡无关的敏感信息。
4. 如涉及故障，提供发生时间和必要的说明。

不要提交银行卡密码、支付密码、短信验证码、私钥或完整的付款凭据安全信息。

我们核实后应说明是否符合条件、核算金额、依据及退款路径。需要补充材料或预计发生延迟时，应说明原因及后续安排；退款应在适用法律或订单约定期限内办理，不以内部审批流程无限期拖延。

## 5. 退款路径与到账

原则上优先退回原支付渠道。原渠道无法退款、涉及渠道限制或需要其他合法方式时，应先核实权属并与你协商，不向未经核实的第三方账户转款。

实际到账时间受银行、支付渠道、币种和结算方式影响。我们完成退款操作后，应提供可核对的处理结果；不能将渠道受理时间等同于已经到账。

**除非你主动选择，不以账户余额、代金券或积分强制替代应退的现金。**账户余额不提供普通提现或因个人原因提出的退款；重复充值、错误扣款及依法应退的未消费款项，仍依具体事实和适用法律处理。赠送额度不等同于现金充值。

## 6. 终止服务与数据

退款涉及终止实例时，应先确认终止时间和数据导出安排。请及时自行备份；资源回收后可能无法恢复。具体见[服务终止规则](./termination.md)。

发生违规或安全事件时，可以依法依约限制服务，但不得把所有未使用款项自动作为罚金没收。损失及可退金额应有明确、合法、与实际情况相符的核算依据。

## 7. 异议与争议

如不同意处理结果，可以在原工单补充证据并申请复核，也可以依法使用支付渠道的争议处理或其他救济途径。提出善意退款异议或行使法定权利，本身不构成恶意拒付或违规。
