# 服务条款

更新时间：2026-10-26 16:17:41（北京时间，UTC+08:00）

本条款适用于通过 [vmaub.com](https://vmaub.com) 购买和使用的全部 VMAUB CLOUD 服务。付款前请阅读本条款及[退款政策](./refund.md)、[禁止行为](./acceptable-use.md)和[服务终止规则](./termination.md)。

## 1. 购买与账户

产品配置、价格、周期及使用限制以购买时的页面和订单为准。请自行确认产品是否符合需求，妥善保管账户、服务器密码、密钥及其他凭据，并及时续费。

**VMAUB CLOUD 不支持任何退款。**

## 2. 服务可用性与 SLA

**所有服务器均不提供 SLA（服务等级协议）保证，不承诺固定在线率、持续可用性、故障恢复时限或基于 SLA 的赔付。**

维护、网络波动、设备故障、安全事件及上游服务异常可能导致性能下降或服务中断。请自行评估使用风险，不要将单台服务器作为需要持续运行的关键业务的唯一依赖。

**免费产品不保证可用时长，平台可随时回收、删除实例及其数据。**

## 3. 数据安全与备份

**平台不对任何服务器上的数据安全、完整性、持久保存或可恢复性作出保证，不提供默认备份或数据恢复承诺。**

请自行做好系统维护、访问控制、凭据保护及独立备份，并定期验证备份可用。重装、删除、故障、到期回收或服务终止均可能造成数据永久丢失，请勿将唯一副本存放在本平台。

## 4. 使用与服务终止

你应遵守产品限制及平台规则，不得实施攻击、诈骗、侵权或其他滥用行为。欠费、违规或存在安全风险时，我们可以限制、暂停或终止相关服务；到期或终止后的资源可能被回收，数据可能被删除。

具体规则见[禁止行为](./acceptable-use.md)及[服务终止](./termination.md)。

如有服务问题或对处理结果存在异议，请通过[站内工单](https://vmaub.com/tickets)联系我们，并提供相关订单或实例编号，不要提交密码、私钥或验证码。
