# 禁止行为

更新日期：2026 年 10 月 26 日

使用 VMAUB CLOUD 服务时，禁止以下行为：

- 实施诈骗、盗刷、非法交易，或传播诈骗、侵权及其他违规内容。
- 发起 DDoS、暴力破解、未授权扫描、入侵或其他网络攻击。
- 部署恶意软件、钓鱼网站、僵尸网络，或窃取他人数据和凭据。
- 发送垃圾邮件、诈骗信息，或提供用于上述行为的中继、代理设施。
- 侵犯他人的知识产权、隐私或其他合法权益。
- 绕过资源配额、计费和安全限制，或恶意干扰其他用户及基础设施。

请遵守产品明确展示的资源与用途限制。发现实例被入侵或遭到滥用时，应及时处理并通过[工单](https://vmaub.com/tickets)联系我们。

对违规或存在紧急安全风险的服务，我们可以采取限制、暂停或终止措施。你可以通过工单提交说明及整改证据，申请复核。
